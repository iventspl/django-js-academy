Before deploy

Upgrade checklist

  • Read the official release notes for every version you cross.
  • Run the full test suite on the target version — not only the new feature you are adding.
  • Check deprecation warnings in CI, not just locally.
  • Review settings and middleware changes in the target release.
  • Test migrations against a copy of production data.
  • Deploy a canary, watch errors, then roll forward or back deliberately.
