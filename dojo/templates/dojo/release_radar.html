The patch policy

What Django promises — and what it leaves to you.

Patch releases are compatible by default.

Stay on the latest patch within your series. Security and data-loss fixes are backported; exceptional incompatibilities are called out.

LTS is a longer window, not a freeze.

5.2 LTS receives security and data-loss fixes through April 2028, but only if you install the patch releases. Old LTS versions still have old bugs.

Security severity is not a “do nothing” signal.

“Low” or “moderate” still matters for exposed endpoints and defence in depth. Read the affected configuration and your threat model.

Your dependencies count too.

Django is one package in a supply chain. Pin versions, monitor advisories, and test upgrades in staging with a real database copy.
