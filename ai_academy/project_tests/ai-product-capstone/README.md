# AI Product Capstone — acceptance test pack

This pack defines the contract for the **AI Product Capstone** project. It is intentionally failing until you implement `starter.py`. Do not edit the tests to make them pass; change the implementation.

## Run

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest -q
```

## Files

- `starter.py` — the interfaces you implement.
- `tests/test_acceptance.py` — the contract. Read the tests before coding.
- `requirements.txt` — runtime and test dependencies.
- `README.md` — this file.

## Rule of the exercise

The tests are a floor, not the whole project. Your real submission still needs the README, evaluation, failure analysis and demo described in the project brief on AI Academy.
