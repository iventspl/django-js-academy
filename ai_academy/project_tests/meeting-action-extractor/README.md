# Meeting Notes → Action Items — acceptance test pack

This pack defines the contract for the **Meeting Notes → Action Items** project. It is intentionally failing until you implement `starter.py`.

## Run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -q
```

The tests cover a small set of patterns. Your submission still needs the 15-snippet fixture, precision/recall report and documented limitations from the project brief.
