# Support Email Triage — acceptance test pack

This pack defines the contract for the **Support Email Triage** project. It is intentionally failing until you implement `starter.py`. Do not edit the tests to make them pass.

## Run

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest -q
```

The tests are a floor. Your submission still needs the 30-email evaluation set, confusion analysis, human-routing policy and README described in the project brief on AI Academy.
