01 · Records

Lists, dicts and sets

record = {"text": "reset password", "label": "account"}
records = [record, {"text": "charged twice", "label": "billing"}]
texts = [r["text"].lower() for r in records]
labels = {r["label"] for r in records}
lookup = {r["text"]: r for r in records}

Use a dict for one record, a list for a batch, a set for uniqueness and a dict comprehension for lookup.

02 · Files

JSON and JSONL

import json

with open("data.json", encoding="utf-8") as f:
    payload = json.load(f)

with open("data.jsonl", encoding="utf-8") as f:
    rows = [json.loads(line) for line in f if line.strip()]

with open("out.jsonl", "w", encoding="utf-8") as f:
    for row in rows:
        f.write(json.dumps(row, ensure_ascii=False) + "\n")

JSON arrays are easy; JSONL streams better for large exports. Always pass an encoding.

03 · Functions

Typed functions and defaults

from dataclasses import dataclass

@dataclass
class Note:
    text: str
    label: str = "unlabelled"

def clean(text: str) -> str:
    return " ".join(text.strip().lower().split())

def chunk(text: str, size: int = 500, overlap: int = 50) -> list[str]:
    if size <= overlap:
        raise ValueError("size must exceed overlap")
    step = size - overlap
    return [text[i:i + size] for i in range(0, len(text), step)]

Hints do not enforce types at runtime; they make the contract visible to tests, editors and mypy.

04 · Pandas

Load, inspect, clean, split

import pandas as pd

df = pd.read_csv("notes.csv")
df = df.drop_duplicates(subset=["text"]).copy()
df["text"] = df["text"].str.strip().str.lower()
df["label"] = df["label"].fillna("unlabelled")

summary = df.groupby("label").agg(
    rows=("text", "size"),
    avg_length=("text", lambda s: s.str.len().mean()),
)

print(df.isna().mean().sort_values(ascending=False).head())

Audit shape, types, duplicates and missingness before modelling. Use .copy() when modifying a filtered frame.

05 · NumPy

Vectorise, don't loop

import numpy as np

scores = np.array([0.2, 0.8, 0.6, 0.4])
labels = scores >= 0.5
positive_rate = labels.mean()

# Broadcasting: normalise every row to zero mean, unit variance.
matrix = np.array([[1.0, 2.0], [3.0, 4.0]])
normalised = (matrix - matrix.mean(axis=0)) / matrix.std(axis=0)

Prefer array operations over Python loops. Verify shapes; broadcasting errors usually mean two dimensions do not align.

06 · APIs

Secrets, timeout, failure

import os, requests

def ask(prompt: str) -> str:
    key = os.environ["LLM_API_KEY"]
    response = requests.post(
        "https://api.example.com/v1/chat",
        headers={"Authorization": f"Bearer {key}"},
        json={"prompt": prompt},
        timeout=20,
    )
    response.raise_for_status()
    return response.json()["choices"][0]["message"]["content"]

Never hard-code keys. Add a timeout and handle provider errors; retry only transient, idempotent calls.

07 · Tests

pytest basics

def test_clean_collapses_whitespace():
    assert clean("  Reset   Password ") == "reset password"

def test_chunk_rejects_bad_overlap():
    with pytest.raises(ValueError):
        chunk("abc", size=10, overlap=10)

Test behaviour, edge cases and failure paths. Mock external providers so the suite is fast and offline.
